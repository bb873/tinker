## Health research multi-agent system

- `health/PROMPT.md`: the orchestrator prompt. Run it in Claude Code with Opus as the main model.
- `health/PROFILE.md`: fill in before running.
- `.claude/agents/health-*.md`: Sonnet and Haiku research, safety, citation, and writing workers.

Outputs land in `health/PLAN.md`, `health/research/`, `health/SYNTHESIS.md`, and `health/REPORT.md`.
